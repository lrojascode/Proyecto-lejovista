# Domain Docs

El repositorio utiliza un layout de dominio single-context.

## Antes de explorar

Leer, cuando existan:

- `CONTEXT.md` en la raíz.
- `docs/adr/` para decisiones relacionadas con el área modificada.

Si todavía no existen, continuar sin solicitar su creación. La skill de modelado de dominio los creará cuando se resuelvan términos o decisiones que deban conservarse.

## Vocabulario

Usar en issues, especificaciones, pruebas y propuestas los conceptos definidos en `CONTEXT.md`. No introducir sinónimos que contradigan el glosario.

Si falta un concepto, reconsiderar el término o registrar la necesidad de modelarlo.

## Conflictos arquitectónicos

Si una propuesta contradice un ADR existente, señalarlo explícitamente en vez de sustituir silenciosamente la decisión.
